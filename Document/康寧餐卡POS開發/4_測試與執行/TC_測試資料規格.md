# TC 測試資料規格

版本 v1.1｜2026-11-08。以下業務資料仍為規劃；本次已建立的 T05 合成流程資料另列於文末，不是正式員工、卡號或登入帳密。A01–A39 仍未執行。

## 角色與裝置

| 代號 | 用途 | 權限/限制 |
|---|---|---|
| ADM | 帳號權限管理者 | 只具核准管理職責，不同於 POS 裝置身分 |
| HR | 員工來源匯入 | 員工維護，不默認可沖正 |
| CARD | 卡務人員 | 正式與臨時卡、同步工作 |
| MEAL | 餐務人員 | 資格與餐期；補登依核准角色 |
| FIN | 財務 | 餐費、結算與核准沖正 |
| OPS | 設備維運 | 設備狀態與重試，無權修改金額 |
| AUD | 稽核唯讀 | 核准範圍查詢，無寫入/匯出則拒絕 |
| POS-A/POS-B | Site-T 的 L-A/L-B | 只能領取自身餐道事件及提交／查自身交易 |


## 員工與卡片

| 資料 | 合成值/條件 | 用途 |
|---|---|---|
| U-A | 員編 SYNTH00000001；測試員工甲；有效正式卡 | 一般與長員編 |
| U-B | 員編 SYNTH00000002；測試員工乙；臨時借卡 | 臨時卡與連刷 |
| U-C | 測試員工丙；有效卡但補助不適用 | 卡有效不等於有補助 |
| U-D | 測試員工丁；已離職／撤銷 | 來源異動、亂序與設備銷碼 |
| C-A/C-B | 字串 0000000101、0000000102 | 前導零與不同餐道 |
| C-LONG | 字串 0000000000103 | 13 字元、不得縮短為 10 |
| C-T | 字串 0000000199 | 臨時卡借還與重發 |
| C-X | 合成未知/掛失卡 | 拒絕與異常 |
| R-A/L-A/POS-A；R-B/L-B/POS-B | 兩組固定對應 | 多餐道、越權與領取競爭 |


## 金額與時間

- 契約守恆範例：總額 8000 minor（NT$80）、公司 5000、DL 0、自付 3000。僅為合成契約案例，不能當客戶補助政策。
- 業務資料集由 Q05/Q06 核准後另建：各身分類別、資格起迄、低於/等於/超過上限、同餐多筆、跨餐道、取消與已結算調整。
- 時間資料包含：餐期端點、非餐期、跨午夜、月底、跨年、設備時差、舊事件晚到與來源版本亂序。
- 測試時鐘可注入測試環境；不得為測試改正式主機時間。
- 設備 frame 與 checksum 不在本版編造；T02 取得原廠樣本、人工刷卡記錄與解析結果後，建立匿名或合成的可重播副本。
- 結算集合至少包含正常、補登、取消、沖正、跨日、遲到及跨餐道，且有獨立人工加總答案。

## 證據保存

每次測試記環境、程式/規則/Mapping 版本、資料集版本、角色、裝置型號韌體、開始時間、案例 ID、預期與實際、事件/交易/批次 ID、證據位置與問題單。截圖遮罩個資；不保存登入密碼、金鑰或完整連線字串。

## 已建立的 T05 資料（2026-11-08）

- [scenarios.synthetic.json](../../../SourceCode/Api/CommonLibrary/Infrastructure/Simulation/scenarios.synthetic.json)：四個獨立開發情境 `employee-a`、`employee-b`、`temporary`、`revoked`，含前導零／13 字元卡碼；API 僅回遮罩卡碼。這些不是上方 U-A～U-D 的完整財務資料集，也沒有宣告補助資格。
- [raw-capture.synthetic.jsonl](../../../Tests/Fixtures/raw-capture.synthetic.jsonl)：任意兩段共 11 bytes，包含二進位／換行，供 Base64 還原、序號／長度／SHA-256 檢查。不是廠商 frame，SHA-256 不是設備 checksum。內容說明見 [Fixtures](../../../Tests/Fixtures/README.md)。
- API 測試注入 TimeProvider 檢查租約過期；同 ID 併發重送回同一紀錄。模擬程序最多各 500 筆、重啟清空；未驗 SQL 原子交易、多人權益併發或跨餐道授權。
- 原始實機取樣放 Git 忽略的 `artifacts/captures` 並受控保存，不將原始卡號與封包直接加入合成 fixtures。本輪只執行合成／loopback 測試。
