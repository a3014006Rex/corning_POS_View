## 本版範圍

- 一期建議：TC-01～TC-05，共 26 項功能；T00–T32 共 33 張工作項目。
- 選配：TC-06-01～TC-06-03，共 3 項功能；T33–T35。未納入一期總數與驗收。
- T00 已完成文件盤點。T04 已建立 API／Vue、POS 預覽、Skills 與原始取樣工具；T05 具合成 API 流程、後台紀錄／測試 CSV 及自動測試，皆為部分實作。正式 Gateway／部署及業務工作未完成。啟動見 [專案 README](../../README.md)，核對與後續關卡見 [前期安排](../AI區/前期規劃核對與開發安排.md)。
- 42 個 API 均是本版提案路由；未查得對應現有正式 API，不應依文件假設已可呼叫。
- A01–A36 是一期測試計畫，A37–A39 屬選配；目前全部未執行。
- 18 週為指定人力與資料到位條件下的排程情境，非固定承諾。見[階段與排程](2_規劃與工作項目/TC_階段與排程.md)。

4. 依工作項目讀設計契約、執行測試，回填[驗收結果](4_測試與執行/TC_驗收結果紀錄.md)與[工作追蹤表](工作追蹤表.md)。

## 維護方式

進度只在工作追蹤表維護；驗收結果只在驗收結果紀錄維護，其他文件以連結引用。工作項目保存驗收標準與每次執行證據，不另維護第二套百分比。

新增規則先記錄來源或決策，更新受影響功能、契約、工作項目及測試。既有測試通過不能替代變更後重測。文件連結採相對路徑，客戶來源原檔保留於根目錄的 `開發前規劃資料`；本規劃文件不包含客戶原始執行檔、資料庫、照片或卡號資料。
