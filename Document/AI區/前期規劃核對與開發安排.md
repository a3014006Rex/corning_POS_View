## 本次前期實作

1. **合成資料與 API 流程**：測試刷卡 → 領取 → 總額確認 → 建立 SIMULATED 紀錄 → 原 ID 查單；有效／撤銷卡、新人不得覆蓋目前人員、重送與過期衝突都有測試。分攤固定標示 `NOT_EVALUATED`，沒有自行定補助公式。
2. **Vue 與後台骨架**：`/#/development` 操作合成流程，`/#/admin/transactions` 查詢及匯出測試 CSV；結果不明時保留原 UUID，先查單再由使用者明確重送原請求。CSV 包含模擬標示，並處理公式型欄位。
3. **RFID 原始取樣／離線重播**：`SourceCode/Gateway/TC_RfidCapture` 要求明確 IP、Port、時限及新輸出檔，不含舊端點預設值；僅接收原始 TCP 片段，不發初始化／ACK／清除命令，不解析卡號。逐段保存 Base64、長度、序號及 SHA-256，重播檢查完整性。
4. **開發隔離**：模擬 API 僅 Development 且旗標開啟、本機來源及指定測試 header 可用；Production 不映射。正式授權邊界仍預設拒絕，DB／設備／正式交易能力仍為 false。

模擬資料限單一程序／測試終端，重啟即消失；事件、Claim、Quote、交易各最多 500 筆。Claim 5 分鐘、Quote 2 分鐘僅為測試租約，不代表核准營運政策。沒有 SQL 原子交易、補助併發、多餐道權限、正式取消沖正或斷線營運能力。

## 驗證證據

本機 .NET solution 測試 22 項（API 16、取樣工具 6）與 Vue 25 項通過，Vue lint／production build 通過。取樣工具驗證包含 loopback TCP 與拆段／合併後位元組一致，並非實體卡機實測。API 測試包含 Production／旗標停用時 404、缺測試 header／外部 Origin 時拒絕，以及相同交易 ID 併發重送只有一筆紀錄。

已另以本機 Chrome 無頭瀏覽器實際操作：模擬刷卡 → NT$80 確認 → SIMULATED → 目前人員／金額清空 → 後台查詢 → 下載 CSV → 撤銷卡拒絕；未捕捉到未處理的 JavaScript 例外。1280px 桌面及 390px 檢視已檢查，390px 無水平溢出。測試腳本為 [simulation-smoke.mjs](../../Tests/Browser/simulation-smoke.mjs)，不使用正式設備或 DB。

收尾另補上離頁時釋放未提交 Claim／清除畫面資料；如果提交已發出或結果不明，離頁保留原 ID 並不釋放該提交，重新載入先查單。三個 AI Skills 驗證通過；搬移後文件及原始 HTML 資源連結已檢查，六個靜態原檔雜湊與搬移前一致。

實際指令、頁面及重播方式見 [執行與偵錯步驟](../康寧餐卡POS開發/4_測試與執行/TC_執行與偵錯步驟.md)。本輪未連接實體 RFID 或舊 DB，未執行 A01–A39／UAT，CI 設定已更新但未宣告雲端工作執行成功。
