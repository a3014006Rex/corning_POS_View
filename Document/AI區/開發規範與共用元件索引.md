# TC 開發規範與共用元件索引

規範入口為 [AGENTS.md](../../AGENTS.md)，啟動方式為 [README.md](../../README.md)。此索引只列目前存在的封裝，不預告尚未實作的 CRUD、登入、日期或附件元件。

| 能力 | 實作 | 使用邊界 |
|---|---|---|
| HTTP／業務失敗 | [http.js](../../SourceCode/Web/src/api/http.js) | 統一 API base、camelCase envelope、traceId、取消及逾時；不自動重送 |
| 系統資訊 | [system.js](../../SourceCode/Web/src/api/system.js) | 基礎能力查詢；不代表 DB／交易可用 |
| 開發模擬 wrapper | [simulation.js](../../SourceCode/Web/src/api/simulation.js) | `/development` 與專用測試 header；不呼叫正式 E14–E18 |
| 合成 POS 流程 | [useSimulationPos.js](../../SourceCode/Web/src/composables/useSimulationPos.js) | API 領取／報價／提交／原 ID 查詢；sessionStorage 只保存復原 UUID，資料限開發程序 |
| 後台版型 | [AdminLayout.vue](../../SourceCode/Web/src/layouts/AdminLayout.vue) | 首版外框，不代表帳號角色完成 |
| 測試紀錄與 CSV | [transaction-lab.vue](../../SourceCode/Web/src/views/admin/transaction-lab.vue)／[simulationCsv.js](../../SourceCode/Web/src/utils/simulationCsv.js) | Development 合成紀錄；CSV 防公式注入，不是財務結算格式 |
| 原始取樣／重播 | [RawCapture.cs](../../SourceCode/Gateway/TC_RfidCapture/RawCapture.cs)／[CaptureCli.cs](../../SourceCode/Gateway/TC_RfidCapture/CaptureCli.cs) | 收 bytes、保存 JSONL 與 SHA-256；無協定解析或設備命令 |
| 終端顯示設定 | [terminal.js](../../SourceCode/Web/src/stores/terminal.js) | laneName／postCode 僅供顯示；localStorage 不存個資、Token 或授權 |
| 設定對話框 | [TerminalSettingsDialog.vue](../../SourceCode/Web/src/components/TerminalSettingsDialog.vue) | `ref.open()` 開啟；API 路徑唯讀、由部署環境設定 |
| POS 預覽 | [usePosPreview.js](../../SourceCode/Web/src/composables/usePosPreview.js) | 合成資料、示範確認及清除，不接正式刷卡與計費 |
| POS 畫面 | [pos-view.vue](../../SourceCode/Web/src/views/pos/pos-view.vue) | 沿用新版靜態版面；開發模式才可切示範狀態 |
| API 分層範例 | [SystemController.cs](../../SourceCode/Api/TC_API/Controllers/SystemController.cs) | Controller → Application → DTO；只有唯讀系統資訊 |
| 回應契約 | [ApiResponse.cs](../../SourceCode/Api/CommonLibrary/Domain/Contracts/ApiResponse.cs) | camelCase、HTTP 與業務狀態、錯誤詳情與追蹤編號 |
| 授權暫存邊界 | [PendingIdentityHandler.cs](../../SourceCode/Api/TC_API/Authentication/PendingIdentityHandler.cs) | 拒絕受保護端點；待 T07 正式替換，不是登入方案 |

前端基礎 UI 採 CoreUI，POS 使用既有設計的獨立樣式。只加入有實際用途的封裝，不先搬入 MHC 的日期、附件、醫療領域元件或完整權限流程。

收尾時按需求核對 API／DTO、載入／錯誤／取消、重複送出、授權餐道與個資清除；必要命令與證據要求由 AGENTS.md 維護。
